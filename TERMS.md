# 2. Descripción del Servicio

Modpack Store es una aplicación de escritorio destinada a facilitar el descubrimiento, adquisición, instalación, actualización, organización y gestión de **modpacks, modificaciones, complementos, configuraciones y otros contenidos relacionados con Minecraft**.

La Aplicación puede permitir, entre otras funciones:

- Descubrir modpacks y contenido relacionado.
- Consultar información, imágenes, descripciones y requisitos técnicos.
- Adquirir determinados contenidos digitales.
- Descargar e instalar modpacks.
- Administrar versiones de modpacks.
- Actualizar automáticamente determinados contenidos.
- Gestionar perfiles o configuraciones de instalación.
- Vincular cuentas externas.
- Acceder a funcionalidades premium.
- Recibir novedades, actualizaciones o notificaciones.
- Consultar información relacionada con comunidades, streamers y creadores.
- Interactuar con servicios de terceros integrados en la Plataforma.

Modpack Store podrá incorporar nuevas funciones, retirar funciones existentes o modificar sustancialmente cualquiera de sus componentes con el objetivo de mejorar, mantener o adaptar el Servicio.
